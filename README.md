# 小白板老師（兒童版 AI 白板家教）

孩子輸入問題、拍照題目或上傳 PDF／文字檔，AI 老師會**邊講邊在白板上畫圖**，孩子可以隨時打斷提問，課後自動產生筆記與小測驗。

- 三種模式：💡 學概念、📝 準備考試、✏️ 寫作業（只給提示、不給答案）
- 三個年級層：小一～小二、小三～小六、國中（用字與深度會跟著調整）
- 十種語言：繁中、簡中、English、日本語、한국어、Español、Français、Deutsch、Tiếng Việt、ภาษาไทย
- 兒童安全：內建內容限制、不收集個資、不儲存孩子輸入

---

## 1. 快速開始清單

- [ ] 電腦已安裝 Node.js 18 以上（終端機輸入 `node -v` 檢查）
- [ ] 解壓縮專案資料夾
- [ ] 複製 `.env.example` 為 `.env`，填入 `ANTHROPIC_API_KEY`
- [ ] Windows：雙擊 `start.bat`；其他系統：`npm install` 後 `npm start`
- [ ] 瀏覽器開 http://localhost:3000
- [ ] 頁面上方**沒有**黃色「示範模式」橫幅，代表已連上 AI

> 想讓 iPad／手機隨時能用 → 看第 9 章「部署到雲端」。

> 沒填金鑰也能開，會進入**示範模式**，只播固定的「三角形」範例課，不花錢，用來確認畫面正常。

## 2. 檔案與資料夾說明

| 路徑 | 用途 |
|---|---|

| `lib/prompt.js` | **老師的性格、兒童安全規則、白板畫法規則、年級與模式設定**都在這。要改老師說話方式改這支 |
| `lib/mock.js` | 示範模式的固定課程內容 |
| `public/index.html` | 頁面結構 |
| `public/style.css` | 外觀（字體、顏色、版面） |
| `public/app.js` | 前端邏輯：白板動畫、播放器、提問、小測驗 |
| `.env.example` | 設定檔範本（金鑰、模型、埠號） |
| `.env` | 你自己建立的實際設定，**含金鑰，不可外流** |
| `Dockerfile` | 雲端容器部署用（用 Render 的 Blueprint 時不需要） |

| `start.bat` | Windows 一鍵啟動（自動安裝套件、開瀏覽器） |
| `package.json` | 套件清單 |
| `node_modules/` | 自動安裝的套件，不用管 |

## 3. 第一次設定

1. 到 Anthropic Console（console.anthropic.com）建立 API Key，並確認帳號有儲值。
   - 注意：這是 **API 帳號**，與 Claude.ai 的 Pro 訂閱是分開計費。
2. 把 `.env.example` 複製一份改名為 `.env`。
3. 用記事本打開 `.env`，填入：
   ```
   ANTHROPIC_API_KEY=sk-ant-xxxx
   CLAUDE_MODEL=claude-sonnet-5-5
   PORT=3000
   MOCK=0
   ```
4. 啟動：
   - Windows：雙擊 `start.bat`
   - Mac／Linux：終端機進入資料夾，執行 `npm install`，再 `npm start`
5. 看到「已連線 Claude，模型：…」代表成功。

## 4. 日常使用

**孩子端**
1. 選年級、語言、模式。
2. 打字問問題，或按「📷 拍照／選圖片」「📄 上傳 PDF／文字檔」。
3. 按「開始上課 ▶」，老師會一邊說一邊畫。
4. 聽不懂就在右下輸入框問，老師會換個方式講。
5. 老師問問題時（✋ 換你回答囉），直接在輸入框回答。
6. 課程結束後自動出現「📒 今天學到」與「🎯 小測驗」。

**按鈕**
- ⏸ 暫停／繼續、⏭ 下一步（跳過目前這步）、🔊 朗讀（用瀏覽器內建語音）、🏠 換題目

**家長／管理者**
- 關閉服務：終端機視窗按 `Ctrl + C`，或直接關掉視窗。
- 換模型：改 `.env` 的 `CLAUDE_MODEL`，重啟。
- 想強制不花錢測試：`.env` 設 `MOCK=1`。

## 5. 輸出在哪裡、怎麼用

- 本工具**不會儲存任何東西**：沒有資料庫、沒有對話紀錄檔、伺服器不記錄孩子輸入的內容。
- 課程、筆記、小測驗只存在瀏覽器畫面上，關掉分頁就消失。
- 想保留筆記：用瀏覽器列印（Ctrl + P）存成 PDF，或截圖。
- 終端機視窗只會出現啟動訊息與錯誤訊息。

## 6. 疑難排解／FAQ

| 狀況 | 原因與處理 |
|---|---|
| 終端機出現 `401 ... invalid x-api-key`，網頁顯示「老師剛剛卡住了」 | **開發時實測遇到。** 金鑰填錯、多了空白或換行。重新複製貼上，確認 `.env` 沒有引號與空格，重啟 |
| 網頁上方黃色橫幅「示範模式」 | 沒填金鑰或 `MOCK=1`。填好金鑰、`MOCK=0`，重啟 |
| 上課畫面底部按鈕被擠出視窗外 | **開發時實測遇到，已修正**（`style.css` 版面改成撐滿視窗高度）。若更新後再出現，確認 `style.css` 是最新版 |
| 瀏覽器 console 出現 `favicon 404` | **開發時實測遇到，已修正**（改用內嵌圖示）。無害 |
| `npm install` 出現 `deprecated node-domexception` 警告 | 實測會出現，套件相依的舊警告，**可忽略** |
| 手機上整頁比螢幕寬、白板右邊與對話框被切掉、輸入框跑出畫面 | **雲端實測遇到，已修正（v1.1.3）。** 原因是 `word-break: keep-all` 讓長中文句子沒有換行點，把版面撐寬。改為只在按鈕、標題等短標籤使用，對話與內文允許換行。若再出現，確認 `style.css` 是最新版 |
| 手機上白板文字太小 | 已修正（v1.1.3）：畫布在手機上會縮小，程式會自動把白板文字放大到實際約 17px 以上，並把文字夾在畫布內 |
| 網頁顯示「老師剛剛卡住了」，Render Logs 出現 tool_choice ... are not supported for this model | **雲端實測遇到，已修正（v1.1.2）。** 新模型不支援「強制使用工具」，程式改為 auto 模式並自動重試。看得到這個 400 錯誤，代表金鑰與儲值都正常 |
| 啟動時顯示「對外開放時必須設定 ACCESS_CODE」就結束 | 這是刻意的保護：`HOST` 不是本機卻沒設密碼，程式拒絕啟動。設好 `ACCESS_CODE` 再啟動 |
| 登入顯示「試太多次了」 | 同一來源 10 分鐘內只能試 8 次，等 10 分鐘 |
| 顯示「今天的上課次數用完了」 | 達到 `DAILY_LIMIT`（預設全站每天 200 次呼叫），隔天自動歸零，或調高設定 |
| 每次重啟雲端服務都要重新登入 | 沒設 `SESSION_SECRET`。設一組固定亂碼 |
| 網頁打不開 | 確認終端機視窗還開著；網址要用 `http://localhost:3000`（不是 https） |
| 埠號被占用（`EADDRINUSE`） | 改 `.env` 的 `PORT=3001`，網址跟著改 |
| 朗讀沒聲音 | **雲端實測遇到。** ①手機／平板的**靜音鍵**開著時，iOS 常會把網頁聲音也關掉，先關靜音並調高音量；②iOS 規定朗讀要在點擊當下啟動，v1.1.4 已修正（按「朗讀」開關會立刻唸一句「朗讀開啟了」，沒聽到就是被靜音或音量為 0）；③仍沒聲音：改用 Safari／Chrome 最新版，並確認系統有該語言的語音（設定→輔助使用→朗讀內容→聲音） |
| 朗讀語音怪 | 朗讀用的是瀏覽器內建語音，各裝置語音包不同；iPad／iPhone 通常有較自然的中文語音 |
| 上傳檔案沒反應 | 單檔限 10MB；支援圖片、PDF、txt／md |
| 白板上的字或圖重疊、跑版 | AI 偶爾排版不佳。請孩子按「換題目」重開，或問「可以重畫嗎？」。可在 `lib/prompt.js` 的 `BOARD_RULES` 加更嚴格的版面規則 |
| 老師講錯 | AI 可能出錯，頁面已提醒孩子向老師或課本確認；重要科目建議大人陪同 |

## 7. 已知限制

- **尚未用真實金鑰做端對端測試**：開發環境沒有可用金鑰。已驗證：示範模式完整流程、瀏覽器畫圖與提問互動、金鑰錯誤時的錯誤處理。AI 實際回傳課程的品質（畫面排版、年級用字是否合適）需要你填金鑰後實測，必要時調整 `lib/prompt.js`。
- 白板只支援基本圖形（線、箭頭、方塊、圓、橢圓、多邊形、文字），沒有數學公式排版（用文字符號代替）、沒有手寫字體。
- 「打斷」是等目前這步或這次回應結束後才改講；不是即時語音對話。
- 不是串流輸出：開課前要等 AI 一次產生完整課程（約幾秒到十幾秒）。
- 沒有帳號、沒有學習紀錄、沒有家長報表。
- 兒童安全規則寫在提示詞中，**無法保證 100% 擋下所有不當內容**，建議家長陪同或在視線範圍內使用。
- 本機模式只綁定 127.0.0.1，其他裝置連不到；要給 iPad 用請走第 9 章雲端部署。
- 密碼是「一組共用通關密碼」，沒有個別帳號，無法分辨是誰在用。
- 限流與每日上限存在記憶體，服務重啟就歸零；若雲端有多個實例，各自計算。
- 雲端部署的設定檔（`render.yaml`、`Dockerfile`）**尚未實際部署驗證**：已驗證在模擬雲端環境變數下可乾淨安裝、啟動、登入；Docker 在開發環境無法執行，未建置測試。

## 9. 部署到雲端（讓 iPad／手機隨時能用）

iPad 不能直接執行這個程式，要把後端放到雲端主機，iPad 用 Safari 開網址即可。以下以 **Render** 為例（其他支援 Node.js 或 Docker 的主機做法類似）。

### 9-1. 先知道的風險

- 放上雲端＝網址是公開的。**沒有 `ACCESS_CODE` 程式會拒絕啟動**，避免陌生人刷你的 API 費用。
- 密碼請用長一點、不要用孩子生日或常見數字。
- 建議在 Anthropic Console 設月額度上限，再加上程式內建的 `DAILY_LIMIT`。
- 主機方案、價格、免費方案是否會休眠，以 Render 官網為準；休眠的方案第一次開會等比較久。

### 9-2. 步驟

1. 把專案放到 GitHub 私人倉庫（**不要**上傳 `.env`，`.gitignore` 已擋）。
2. 註冊 Render（render.com），用 GitHub 登入並授權該倉庫。
3. 選 **New → Blueprint**，選你的倉庫，Render 會讀取 `render.yaml`。
4. 依畫面填兩個「手動」環境變數：
   - `ANTHROPIC_API_KEY`：你的金鑰
   - `ACCESS_CODE`：給孩子的通關密碼
5. 部署完成後取得網址（`https://xxx.onrender.com`），先用電腦瀏覽器測：
   - 會先看到登入畫面、輸入密碼進得去
   - 上方**沒有**黃色「示範模式」橫幅
6. 用 iPad Safari 開同一個網址。

### 9-3. 在 iPad 加到主畫面

Safari 打開網址 → 點分享鍵 → 「加入主畫面」。之後會像 App 一樣全螢幕開啟，圖示是藍底白板。

### 9-4. 環境變數一覽

| 變數 | 必填 | 說明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 是 | Claude API 金鑰 |
| `ACCESS_CODE` | 雲端必填 | 通關密碼 |
| `HOST` | 雲端 | 設 `0.0.0.0`（`render.yaml` 已帶） |
| `NODE_ENV` | 雲端 | 設 `production`（cookie 加 Secure） |
| `SESSION_SECRET` | 建議 | 固定亂碼；`render.yaml` 會自動產生 |
| `DAILY_LIMIT` | 否 | 全站每天最多呼叫 AI 次數，預設 200 |
| `HOURLY_PER_IP` | 否 | 每個來源每小時上限，預設 60 |
| `CLAUDE_MODEL` | 否 | 模型名稱 |
| `PORT` | 否 | Render 會自己指定，不用設 |

### 9-5. 之後怎麼更新

改完程式 → 推到 GitHub → Render 自動重新部署。換密碼：到 Render 改 `ACCESS_CODE` 再重新部署（已登入的孩子會因為簽章不變仍可使用到 30 天期滿；要全部踢出請同時換 `SESSION_SECRET`）。

### 9-6. 雲端排解

| 狀況 | 處理 |
|---|---|
| 部署失敗、Logs 出現「必須設定 ACCESS_CODE」 | 環境變數沒填 `ACCESS_CODE` |
| 打開網址一直轉圈很久 | 免費方案閒置約 15 分鐘會休眠，喚醒要約 1 分鐘；給孩子用前可先自己打開一次叫醒它。想避免休眠只能改付費方案（需先在 Render 設定付款方式） |
| Render 顯示「Payment method removed」或建立服務被擋 | 帳號沒有付款方式時只能建免費服務。確認 `render.yaml` 有 `plan: free` |
| 登入成功但馬上又被要求登入 | 網址用了 http；雲端 cookie 要 https。確認用 `https://` 開 |
| 費用比預期高 | 調低 `DAILY_LIMIT`，並在 Console 設上限 |
